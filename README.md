## 📦 HƯỚNG DẪN ĐẨY LÊN GITHUB PAGES TRONG 2 PHÚT

1. Mở PowerShell hoặc Terminal tại thư mục này:
   ```bash
   git init
   git add .
   git commit -m "Khoi tao website CLB Thanh Nien Khoi Nghiep"
   ```
2. Tạo một Repository mới trên GitHub (Ví dụ: `thanh-nien-khoi-nghiep`).
3. Liên kết và đẩy code lên:
   ```bash
   git branch -M main
   git remote add origin https://github.com/TÊN_GITHUB_CỦA_BẠN/thanh-nien-khoi-nghiep.git
   git push -u origin main
   ```
4. Kích hoạt GitHub Pages:
   - Vào **Repository trên GitHub** -> chọn tab **Settings**.
   - Menu bên trái chọn **Pages**.
   - Tại mục **Build and deployment** -> **Branch**: Chọn `main` và thư mục `/(root)` -> Nhấn **Save**.
   - Sau 1 - 2 phút, website của bạn sẽ hoạt động trực tiếp tại địa chỉ:  
     `https://TÊN_GITHUB_CỦA_BẠN.github.io/thanh-nien-khoi-nghiep/`
